# A nice dark theme for JetBrains IDEs

Adapted from [Subtheme](https://github.com/subtheme-dev)'s [Monokai Pro theme](https://github.com/subtheme-dev/monokai-pro). I pair it with a colorscheme from [dinbtechit](https://github.com/dinbtechit)'s [VSCode Theme](https://github.com/dinbtechit/vscode-theme).

![Screenshot](https://github.com/adityasz/nice-dark-theme/blob/master/screenshots/screenshot.png?raw=true)

To modify the theme, make changes to the
[template](https://github.com/adityasz/nice-dark-theme/blob/master/template/theme.json)
and [colors](https://github.com/adityasz/nice-dark-theme/tree/master/colors),
and run [`build.py`](https://github.com/adityasz/nice-dark-theme/blob/master/build.py).
See [this](https://plugins.jetbrains.com/docs/intellij/developing-themes.html)
for build instructions.
